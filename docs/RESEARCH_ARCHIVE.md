# Research archive

The phase reports and rotation investigations preserve the development record, including failed attempts. Some older pages describe earlier defaults. The public README and GETTING_STARTED guide describe the final retained-map-recovery-v10 release.

Paths under data/ and results/ in these reports refer to private development evidence, not downloadable files. Raw indoor recordings, personal environment reports, credentials, and machine-specific session notes are deliberately excluded. The published numbers are reported development measurements; without the original recordings this repository does not independently reproduce those numbers. The source and automated tests are included.

See PHASE8_RESULTS.md for a readable final assessment. The project remains a proof of concept; Phase 9 and drone deployment were not implemented.
